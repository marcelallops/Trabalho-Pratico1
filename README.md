# Trabalho Prático I — Algoritmos e Estruturas de Dados II

Repositório com as soluções do Trabalho Prático I da disciplina **Algoritmos e Estruturas de Dados II**, do curso de Ciência da Computação/Sistemas de Informação da PUC Minas.

## Sobre o trabalho

O TP1 é composto por 12 exercícios envolvendo manipulação de strings, cifragem, recursividade e validação de dados, implementados em **Java** e **C**, seguindo as regras específicas da disciplina:

- Em Java: apenas tipos primitivos e as classes `MyIO`, `String` (somente `charAt` e `length`) e `Scanner`.
- Em C: apenas tipos primitivos e funções de `stdio.h` e `stdlib.h`.
- Métodos recursivos não podem usar estruturas de repetição, variáveis globais, ou parâmetros extras além de um contador.
- Cada questão é submetida como um único arquivo (`.java` ou `.c`).

## Como compilar e executar

### C
```bash
gcc NomeDoArquivo.c -o NomeDoArquivo
./NomeDoArquivo
```

### Java
```bash
javac NomeDoArquivo.java
java NomeDoArquivo
```

A entrada é lida via terminal (stdin), linha por linha, conforme especificado em cada exercício.
